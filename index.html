05

Ekspor XML

Status validasi Belum divalidasi

Ekspor menghasilkan XML proyek Alight Motion dengan dua pilihan mode sejak v0.5.0. Representasi isi: satu shape (layer) tersendiri per komponen siluet — pemisah layer (AM-4) — sehingga tiap bagian (kerah, lengan, badan, dst.) dapat dipilih dan dianimasikan sendiri di timeline; terbukti tampil di perangkat nyata (TS-1). Representasi garis (VE-3): setiap goresan line art ditulis sebagai satu centerline dengan path-stroke, tanpa garis ganda akibat dua tepi pita. Warna layer dapat berupa satu warna pilihan atau warna asli per komponen hasil sampling piksel sumber (CV-1). Keyframe animasi menyusul pada backlog AN-1; mode garis dan warna asli menunggu uji lapangan (lihat docs/SDD.md).

GAYA GERAK

Preset Animasi

Preset berikut dapat dipratinjau langsung di Studio, pada pratinjau raster maupun hasil vektor. Impor dan tampilan shape statis terbukti di lapangan (TS-1); penerapan preset ke keyframe XML menyusul setelah semantik keyframe diverifikasi melalui uji impor nyata (backlog AN-1).

Silhouette Reveal

Siluet muncul dari skala kecil dengan transisi opasitas halus, lalu menghilang dan berulang sesuai durasi.

Parameter: durasi 0,5–6 detik; intensitas mengatur skala awal.

Pratinjau lokal — keyframe XML menyusul

Scale Pulse

Siluet membesar dan mengecil secara periodis; intensitas menentukan amplitudo denyut.

Parameter: durasi 0,5–6 detik; intensitas mengatur amplitudo skala.

Pratinjau lokal — keyframe XML menyusul

Rotation Motion

Siluet berputar bolak-balik mengikuti sudut yang ditentukan intensitas.

Parameter: durasi 0,5–6 detik; intensitas mengatur sudut putar.

Pratinjau lokal — keyframe XML menyusul

TENTANG ALAT INI

Tentang Naze Vector

Naze Vector adalah alat berbasis peramban untuk mengubah gambar menjadi siluet vektor animasi dengan target ekspor XML untuk Alight Motion.

Status Modul

ModulStatusKeterangan
Impor dan Normalisasi GambarTersediaPNG, JPG, WebP; dinormalisasi hingga 1400 piksel.
Pemrosesan Siluet (raster)TersediaAmbang luminansi, mode gelap/terang, warna siluet; pratinjau dihitung pada resolusi kerja maks 700 px (P1), ekspor resolusi penuh.
Pembangkit Path SVGTersediaVE-1: kontur marching squares plus penyederhanaan RDP; multi-komponen dan lubang internal didukung (VE-2 terhubung ke kontrol tingkat penyederhanaan); tabel tepi bit-packed tanpa perubahan keluaran (P1).
Pratinjau Animasi LokalTersediaTiga preset dengan durasi dan intensitas, pada raster dan vektor.
Desain Antarmuka (v0.3.0)TersediaDS-1: identitas visual Imperfect by Design; fungsionalitas pipeline tidak berubah.
Adapter XML Alight MotionTersedia (lokal)AM-1/AM-2/AM-3/AM-4/AM-5: satu layer shape statis per komponen siluet (pemisah layer, pivot per bagian) atau satu layer garis centerline per goresan (path-stroke); struktur scene mengikuti pola ekspor asli (prolog, precompose, retime, mediaFillMode); outline pada tag path sesuai parser asli Alight Motion; keyframe menyusul (AN-1).
Validasi XMLTersedia (lokal)XV-1/XV-2: well-formedness, prolog, atribut wajib, pola atribut ekspor asli, ID unik, rentang waktu, format warna.
Ekspor XMLTersedia (lokal)EX-1: unduh .xml lokal; mode isi terbukti tampil di lapangan (TS-1); mode garis (VE-3) dan warna asli per komponen (CV-1) tersedia sejak v0.5.0 dan menunggu uji lapangan; verifikasi lanjutan keluaran multi-layer menyusul.

Kompatibilitas

Alight Creative tidak memublikasikan spesifikasi resmi untuk format XML proyek atau preset. Referensi yang digunakan saat ini adalah dokumentasi komunitas hasil rekayasa balik dan konverter pihak ketiga. Karena itu, Naze Vector tidak mengklaim kompatibilitas impor apa pun pada tahap ini. Klaim kompatibilitas akan diberikan hanya setelah berkas XML yang dihasilkan lulus uji impor nyata di Alight Motion pada perangkat Android.
